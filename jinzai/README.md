- 有料職業紹介事業 13-ユ-311170（取扱職種：全職種／取扱地域：国内・フィリピン共和国）
- 登録支援機関 19登-001053 はグループのNPO法人日比交流支援機構の登録なので、このページには載せていない

## 書き方のルール
- 特定技能で派遣できるのは農業・漁業だけ。派遣は「特定技能（農業）」として書く
- 有料職業紹介は建設業務（現場作業）・港湾運送業務を扱えない旨を注記する
- 「申請代行」とは書かない（行政書士法）。料金は載せない。問い合わせフォームは置かない（電話・メールのみ）

## 公開方法
`index.html`、`css/`、`js/`、`img/` を、サーバーの `/jinzai/` にアップロードしてください。

## 編集とビルド
```bash
cd jinzai && npm install
npm run build   # index.html のクラスを変更したら必ず実行
```
