# 中古車販売LP（/usedcar/）

株式会社delta（https://delta-inc.jp/）の中古車販売LPです。
既存の新規事業LP（`/recruit-cleaning/`）と同じ **静的HTML ＋ Tailwind CSS（ビルド済みCSS）** で作っています。

## ページの構成
1. ファーストビュー（古物商許可 東京都公安委員会許可 第303272009420号 を明記）
2. 取扱車両（写真ギャラリーと諸元）
3. 会社情報・許可
4. ご購入の流れ
5. お問い合わせフォーム
6. フッター（古物商許可を明記）

## 公開方法
`index.html`、`css/`、`js/`、`img/` を、サーバーの `/usedcar/` にアップロードしてください。
`src/`、`tailwind.config.js`、`package*.json`、`node_modules/` は開発用なので、アップロードは不要です。

## 編集とビルド
```bash
cd usedcar && npm install
npm run build   # index.html のクラスを変更したら必ず実行
```

## 車両の追加・差し替え
- `index.html` の `<article data-gallery>` を複製し、写真・車名・諸元を書き換えます。
- 写真は `img/` に置きます（縦長 1200×1600 を想定）。
- **ナンバープレートや人物の写り込みは、必ずぼかしてから使用してください。**
  現在の写真は、ナンバー・ポスター・ミラーへの人物の映り込みにぼかしを入れ、EXIF（位置情報など）を削除してあります。

## フォーム送信の接続
- `<form id="contact-form" data-endpoint="">` に送信先URLを設定します。
  - **空のとき**：デモモード（送信せずに完了画面を表示）
  - **URLを設定したとき**：`FormData` を POST し、2xx 応答で完了画面を表示
- 送信処理は `js/main.js` の `submitInquiry()` 1か所にまとめてあります。
- 送信される項目

| name | 内容 |
|---|---|
| `name` | お名前（必須） |
| `tel` | 電話番号（必須・半角に変換済み） |
| `email` | メールアドレス（必須） |
| `message` | お問い合わせ内容（任意） |
| `privacy` | `agree` |
| `website` | ハニーポット（値が入っていたら破棄） |
| `source` | `usedcar-lp` |

- **サーバー側でも、必ず同じ内容のバリデーションを行ってください。**
